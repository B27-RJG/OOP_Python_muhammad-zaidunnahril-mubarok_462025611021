# Final Project - Peminjaman Perlengkapan Pernikahan

Aplikasi ini dikembangkan sebagai tugas akhir mata kuliah Pemrograman Berorientasi Objek (PBO).

## Struktur Proyek
- `TugasAkhirPBO.py`: File utama aplikasi berbasis Streamlit.
- `requirements.txt`: Daftar pustaka yang diperlukan untuk menjalankan aplikasi.

## Prasyarat
- Python 3.8 atau yang lebih baru.
- Koneksi internet untuk menginstal library.

## Cara Menjalankan Aplikasi
1. Buka terminal di folder proyek ini.
2. Instal library yang dibutuhkan dengan perintah:
   ```bash
   pip install -r requirements.txt
